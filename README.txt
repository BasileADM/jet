JET — mini site (HTML/CSS/JS)
===========================

Contenu :
- Menu latéral (burger) qui s'ouvre + overlay
- Page d'accueil avec sections (LOUANGE / TEMP FRAT / TOPO / ADORATION / POT-FRAT)
- Clic sur un titre => affiche/masque le texte (accordéon, 1 ouvert à la fois)

Démarrer :
1) Ouvrez index.html dans votre navigateur
2) Optionnel : remplacez les images de fond dans /assets/img/
   - section1.jpg ... section5.jpg
   (vous pouvez mettre n'importe quelles images, même des .png : adaptez le HTML)

Déploiement :
- Copiez le dossier sur votre serveur (Apache/Nginx) et servez index.html.
